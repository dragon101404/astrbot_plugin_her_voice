# 语音与晚安电台

用本机 GPT-SoVITS V4 给大肥鱼合成语音。工具只在 Proactive Chat 已绑定的主人网页私聊可用。

## 安装与更新

需要 AstrBot 4.29.1 或更新版本、本机 GPT-SoVITS V4，以及已配置主人会话的 Proactive Chat。

发布后，可在 AstrBot 的插件管理页通过仓库地址安装。已有本地安装时，给该插件选择仓库作为安装源后，后续版本可用卡片上的「更新」拉取。「重载」会重新读取当前磁盘上的插件代码。

安装后，在插件设置中填写本机 GPT-SoVITS 目录和角色名。模型权重和参考音频由本机 GPT-SoVITS 提供。

## 怎么用

- **短语音**：说「用开心的语气跟我说声晚安」或「用语音读一下这段」。大肥鱼也可以自主选用一条短语音。
- **晚安电台**：说「给我来一期晚安电台」。它会按需生成一段约 300–500 字的节目，再用同一个声音合成。
- **调设置**：在 AstrBot 的插件卡片点齿轮。可调默认语气、语速、分句停顿、自主短语音开关和冷却、电台开关。

## 角色与语气

默认流萤，分句停顿 **0.25 秒**。流萤有四种实际参考语气：中立、开心、一点悲伤、中立谨慎。换角色时，插件会按角色名寻找 V4 的 GPT 权重、SoVITS 权重和带语气标签的 WAV。每个角色只用自己目录里的参考音频。配置的默认语气在当前角色不可用时，会选用该角色自己的参考音频。点名使用不可用的语气时，插件会提示可用选项。

## 本地服务

首次合成时会启动本机 `api_v2.py`，默认监听 `127.0.0.1:9881`。五分钟没有合成请求时会释放进程。出现启动错误时，在 `data/plugin_data/astrbot_plugin_her_voice/sovits.log` 查看原因，并确认 GPT-SoVITS 路径、V4 权重和参考音频都在。
